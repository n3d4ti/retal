# Handoff

Multiplayer added (host chose: both Co-op and Dogfight, picked when creating a match). Files: src/wsproto.rs (hand-written SHA-1/base64/WebSocket frames), src/server.rs + src/bin/retal-server.rs (lobby: HELLO/LIST/CREATE/JOIN/LEAVE/R/T relay, rooms public or password, 8 max, closes when host leaves; also serves web/), src/net.rs (native thread ws client / wasm via web/net.js plugin; browser text entry via window.prompt), src/mp.rs (match sync: P own state 15Hz, W host snapshot 10Hz, H/HG hits to host, K kills, D bot damage, PH/PK dogfight, FL flares), src/lobby.rs (menus), game.rs (MatchMode, Remote, NetOut, authority=host runs bots; clients mirror). Desktop game auto-starts an embedded server on port 8787 if none reachable at localhost. Self-test 'multiplayer' step runs a full in-process flow incl. wrong password, public join, dogfight kill. Preview flags: --lobby, --create, --title, --touch-ui with --screenshot. Cargo default-run=retal; build_web.sh builds --bin retal. Not done: host migration, persistence of names, NAT/internet hosting help (needs a reachable server; phones need HTTPS -> wss). One unexplained early test stall did not reproduce in 9 later runs.
