# Handoff

Static site: app/public-html (built by ./build_static.sh -> runs build_web.sh then copies index.html, config.js (kept if edited), mq_js_bundle.js, tilt.js, net.js, retal.wasm, manifest.webmanifest, icon-192/512.png, .nojekyll). Works from a sub-folder on a plain static server (tested headless). Multiplayer on static hosts: server address from ?server=, config.js RETAL_SERVER, last working address (localStorage), else same-origin /ws; https pages need wss://. deploy/STATIC-HOSTING.md + deploy/github-pages.yml (example workflow to copy into .github/workflows). Mobile tuning: tilt.js smoothing 0.35, re-level on screen rotation (epoch), tilt state (waiting/on/blocked/none) shown on title, wake lock, safe-area canvas, PWA manifest; Rust: tilt sensitivity LOW/NORMAL/HIGH on pause screen (touch), phone draws 22-cell ground radius + 5 mountain tiles with shorter fog. Self-test now uses 20 sim steps per drawn frame and no vsync in test modes (fixes >90 s timeouts when the window is covered); runs in <1 s. Not tested on a real phone.
